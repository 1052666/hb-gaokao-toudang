# 湖北高考投档分数线查询

静态查询网站，包含湖北高考投档线、一分一段表和院校地图。

- 本科投档线：2026 年数据
- 专科投档线：2025 年参考数据
- 专科专业、计划数、学费：阳光高考 2025 招生计划

## 本地 AI 双模式

本地开发时用 Node.js 启动同源服务：

```powershell
node local-server.mjs
```

然后打开 `http://127.0.0.1:8787/ai.html`。

- 普通模式：使用站内完整院校数据，按需调用联网检索。
- 张雪峰模式：运行时原样读取 `skills/zhangxuefeng-skill/SKILL.md`，并调用站内数据、一分一段和联网检索工具。
- 本地联网检索通道：必应、360 搜索、官方站点定向。
- GitHub Pages 静态联网检索：浏览器通过 Jina Reader 读取 Yahoo、百度搜索结果；两个主通道都失败时，再使用 RSS2JSON 读取 Bing RSS 作为降级。

`local-server.mjs` 是本地搜索服务，适合本地开发和更完整的多来源检索。GitHub Pages 没有服务端运行环境，线上页面会自动切换到静态检索回退；第三方 RSS 服务不可用时，站内数据和一分一段查询仍可正常使用。
