# 湖北高考投档分数线查询

静态查询网站，包含湖北高考投档线、一分一段表和院校地图。

- 本科投档线：2026 年数据
- 专科投档线：2025 年参考数据
- 专科专业、计划数、学费：阳光高考 2025 招生计划

## 本地 AI 双模式

本地开发时用 Node.js 启动同源服务：

```powershell
node local-server.mjs
```

然后打开 `http://127.0.0.1:8787/ai.html`。

- 普通模式：使用站内完整院校数据，按需调用联网检索。
- 张雪峰模式：运行时原样读取 `skills/zhangxuefeng-skill/SKILL.md`，并调用站内数据、一分一段和联网检索工具。
- 联网检索通道：必应、360 搜索、官方站点定向。

`local-server.mjs` 是本地搜索服务。纯 GitHub Pages 部署没有服务端运行环境，直接打开线上静态页面时联网检索工具会明确显示不可用，站内数据功能不受影响。
